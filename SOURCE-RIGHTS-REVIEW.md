# Public recorder scope and instrument conditions

This package records a previously assigned integer CFS grade from 1 to 9. It does not administer the CFS, assign a grade from symptoms or dementia severity, provide official clinical descriptors, or reproduce the developer's card or translations.

The repository code license does not grant permission for the CFS instrument. ELUCENIA owner authorization is not established. The developer's current permission page requires a request for tool use and treats translations as derivatives; non-commercial requests are usually free, which does not establish an individual grant.

Official conditions: https://www.dal.ca/sites/gmr/our-tools/permission-for-use.html

The README of the previous Git commit is preserved in Git history and the private immutable audit baseline. It is not copied into this public revision, because its historical dementia-to-grade wording is incorrect. Original LICENSE, NOTICE, authorship and protected legal/support files remain byte-exact. The current MIT numeric component notices remain separate from the Apache standalone wrapper.

The ten documentation files explain numeric-recording input, output and limits in ten languages. They are authorial interface documentation, not authorized or professionally approved translations of the CFS instrument. Technical grade-identity and input-refusal tests do not validate clinical grading, prognosis, the scale, or its translations.
